# NLP-Final-Exam

This is the final exam project of Sven Kurth (175866), Daniel Henke (176182), Margherita Grosso (176786) & Luca Gudi (175880) for the class Natural Language Processing and Text Analytics [CDSCO1002U] at Copenhagen Business School.

The project analyzes the sentiment and topics of presidential debates in the United States from 1960-2024.

The main project file is in the Jupyter Notebook "Final Notebook". The .csv files are automatically created within the notebook but can be utilized to skip preprocessing steps. The main data source is data_dir, where the .json and .txt files live.

Lastly, the working_files includes all temp files used in creating this final report.
